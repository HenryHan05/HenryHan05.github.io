**Data Analysis Project**

[GitHub Repository](https://github.com/HenryHan05/vehicle-emissions-analysis)

Analyzed a multi-thousand-row vehicle dataset to investigate relationships between vehicle characteristics, fuel efficiency, and CO2 emissions.

Methods included:

- Permutation testing
- Pearson correlation analysis
- Linear regression
- Group comparison between diesel and gasoline vehicles

The project applied statistical methods to quantify how engine-related features influence emissions and fuel efficiency.

Technologies:

Python, Pandas, NumPy, Matplotlib, Statistical Analysis

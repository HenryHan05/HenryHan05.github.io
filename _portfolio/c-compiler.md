**Course Project**

[GitHub Repository](https://github.com/HenryHan05/C-Compiler-Class-Project-2025-12)

Developed a miniature C compiler through an LLM-assisted, prompt-engineering-based development workflow.

The compiler pipeline includes:

- Lexical analysis
- Syntax analysis
- Intermediate code generation
- Stack-based virtual machine execution

The project focused on understanding compiler architecture and using iterative testing and debugging to improve implementation correctness.

Technologies:

C++, Compiler Design, Virtual Machine, Debugging
